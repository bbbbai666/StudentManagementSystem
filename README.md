# 控制台学生管理系统

## 功能

| 编号 | 功能           | 说明                                 |
|------|----------------|--------------------------------------|
| 1    | 新增学生       | 输入学号/姓名/年龄/专业，学号不可重复 |
| 2    | 删除学生       | 按学号删除                           |
| 3    | 修改学生       | 按学号定位，字段留空则保留原值        |
| 4    | 按学号查询     | 精确匹配                             |
| 5    | 按姓名模糊查询 | 关键字包含即命中，忽略大小写          |
| 6    | 列出全部学生   | 表格化输出                           |
| 0    | 退出系统       | -                                    |

## 文件结构

```
StudentManagementSystem/
├── Student.java          # 学生实体类
├── StudentManager.java   # 管理逻辑层（增删改查）
├── Main.java             # 控制台交互入口
└── README.md             # 本说明文件
```

## 编译与运行

### 方式一：命令行（推荐）

打开终端，进入项目目录：

```bash
cd Desktop/StudentManagementSystem

# 编译（生成 .class 文件）
javac -encoding UTF-8 *.java

# 运行
java Main
```

> Windows 的 cmd / PowerShell 中文若乱码，先执行 `chcp 65001` 切换到 UTF-8。

### 方式二：IDE

用 IntelliJ IDEA / Eclipse / VS Code 打开 `StudentManagementSystem` 文件夹，直接运行 `Main.java` 的 `main` 方法。

## 技术说明

- **存储方式**：内存 `ArrayList`，程序退出后数据不保留（如需持久化可扩展为文件 / 数据库）。
- **学号唯一性**：新增时会校验学号是否已存在。
- **模糊查询**：使用 `String.contains` + 忽略大小写。
- **输入容错**：年龄非法会提示重新输入；修改时字段留空可保留原值。
- **JDK 版本**：需要 JDK 8 及以上（使用了 Stream / Optional）。
